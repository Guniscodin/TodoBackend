# 📝 Todo Backend

A simple Todo backend built with Express, MongoDB, Mongoose, and TypeScript as a practice project.

## ✨ Features

- 🔐 JWT Authentication
- ✅ Create, Read, Update and Delete tasks
- 👤 User authorization
- ✔️ Input validation
- 🚦 Rate limiting
- 🛡️ Security middleware
- 📄 REST API

## 🚀 Getting Started

```bash
git clone <your-repo-url>
cd <repo-name>
npm install
```

Create a `.env` file and add your environment variables.

Start the development server:

```bash
npm run dev
```

## 📂 Project Goal

This project was created to practice building a backend API using TypeScript, Express, MongoDB, and Mongoose while following good backend development practices.
